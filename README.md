# 🚴 Swiggy Sales & Customer Analytics Dashboard
**Interactive Excel Analytics & Executive KPI Dashboard**

## 📌 Project Overview
This project presents an end-to-end analysis of Swiggy's order transactional dataset using Microsoft Excel. Utilizing advanced data analytics techniques—such as Pivot Tables, Dynamic Slicers, Custom KPI Cards, and Regional Heatmaps—this dashboard delivers actionable insights into sales performance, customer ratings, ordering patterns, and regional demand distributions to support data-driven decision-making.

## 🛠️ Tools & Excel Features Utilized
* **Data Cleaning & Preparation:** Power Query and Excel Formulas (Handling missing values, data type standardization, and date hierarchy extraction).
* **Data Modeling & Summarization:** Pivot Tables and Calculated Fields for dynamic aggregation.
* **Interactive Controls:** Dynamic Slicers for cross-filtering by Category, Month, and Restaurant Name.
* **Data Visualization:**
  * **Sales by State:** Regional heatmap visual illustrating geographic distribution.
  * **Monthly & Daily Trends:** Combo and bar charts to identify peak demand periods and seasonality.
  * **Top Performing Cities:** Horizontal bar charts highlighting top revenue-generating cities.
  * **Executive KPI Cards:** Modern, structured UI layout displaying high-level summary metrics.

## 🚀 How to Explore
1. Download the `Swiggy Dashboard.xlsx` file from this repository.
2. Open the file in Microsoft Excel.
3. Navigate to the **Dashboard** sheet and interact with the Slicers (Months, Category, Restaurant Name) to explore dynamic cross-filtering and insights!
