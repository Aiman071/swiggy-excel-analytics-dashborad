# 🚴 Swiggy Sales & Customer Analytics Dashboard
**Interactive Excel Analytics & Executive KPI Dashboard**

## 📌 Project Overview
Is project mein Swiggy ke order transactional data ko Microsoft Excel ke advanced analytics tools (Pivot Tables, Custom KPI Cards, Dynamic Slicers, aur Regional Mapping) ka use karke analyze kiya gaya hai. Dashboard business executives ko sales performance, order volumes, customer feedback, aur geographic distribution ke high-level actionable insights provide karta hai.

---

## 📊 Key Metrics & Business KPIs
* **Total Sales Revenue:** ₹53.01M
* **Average Customer Rating:** 4.34 ⭐
* **Average Order Value (AOV):** ₹268.51
* **Total Feedback Counts:** 5.59M
* **Total Orders Processed:** 197.43K

## 🛠️ Key Tools & Excel Features Used
* **Data Cleaning & Preparation:** Power Query / Excel Functions (Handling null values, data type conversion, date hierarchy extraction).
* **Data Summarization:** Pivot Tables & Dynamic Calculation Fields.
* **Interactive Elements:** Category, Month, aur Restaurant Name ke Dynamic Slicers.
* **Data Visualization:** 
  * **Sales by State:** Regional heatmap/map visual for geographical distribution.
  * **Monthly & Daily Trends:** Combo & bar charts for peak demand identification.
  * **Top Performing Cities:** Horizontal bar ranking for top revenue cities.
  * **Executive KPI Cards:** Modern card layout displaying overall business metrics.

## 🚀 How to Explore
1. Repository se `Swiggy Dashboard.xlsx` file download karein.
2. Microsoft Excel mein file open karein.
3. Dashboard tab par Slicers (Months, Category, Restaurant Name) par click karke cross-filtering aur dynamic insights explore karein!
